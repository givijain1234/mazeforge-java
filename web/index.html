How to read the race

  • Both racers replay one expansion per tick. Browser animation time says nothing about algorithm speed, so the numbers to compare are cells expanded, path steps and path cost. They come straight from the Java code.
  • Terrain costs 1 to 9 (shaded cells). BFS minimises steps and ignores cost. Dijkstra and A* minimise total cost. With loops above 0% a maze has several routes, so the three can disagree.
  • A* uses Manhattan distance, which never overestimates here (the cheapest cell costs 1), so it matches Dijkstra's cost while usually expanding fewer cells.
  • The same seed and settings always rebuild the same maze. The link in your address bar is shareable.

Source and tests: GitHub. Java runs in the browser with CheerpJ by Leaning Technologies (Community License). Maze algorithms follow Jamis Buck's write-ups; A* follows Hart, Nilsson and Raphael (1968).
